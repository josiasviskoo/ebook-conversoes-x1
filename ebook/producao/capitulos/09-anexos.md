# Anexo A: Plano de treinamento de 30 dias

Implanta o Método X1 em quatro semanas, com **30 a 45 minutos de treino por dia**, sem parar a operação.

**Dia 0:** cada pessoa lê a abertura e o capítulo 1; o líder registra a **linha de base** (tempo de 1ª resposta, taxa de resposta, fechamento e conversão por campanha); o time recebe os anúncios no ar; cada vendedor separa 5 conversas recentes (2 ganhas, 3 perdidas).

| Dia | Estudo | Prática / entregável |
|---|---|---|
| | **Semana 1: soar como gente** | |
| 1 | Cap. 2 | Achar os sinais robóticos nas suas 5 conversas |
| 2 | Cap. 3 | Reescrever 5 frases genéricas de forma específica |
| 3 | Cap. 4 | Gravar 3 áudios de 30 a 60s e avaliar em dupla |
| 4 | Cap. 5 | Ativar a mensagem de ausência e combinar o SLA |
| 5 | Revisão | Roleplays 1 e 3 + reunião de sexta (conversa boa e ruim) |
| | **Semana 2: abordagem e descoberta** | |
| 6 | Cap. 6 | 3 aberturas para clique e 3 para formulário do anúncio |
| 7 | Cap. 7 | Revisar o perfil do WhatsApp Business e as provas do time |
| 8 | Cap. 8 | Banco com 10 a 15 perguntas do seu produto |
| 9 | Prática | Nomear a dor em todas as conversas do dia |
| 10 | Revisão | Roleplays 2 e 4 |
| | **Semana 3: Método X1 e perfis** | |
| 11 | Cap. 9 | Mapear 2 conversas ganhas nas 8 etapas |
| 12 | Cap. 10 | Escolher o framework do time e escrever as perguntas |
| 13 | Cap. 11 e 12 | Classificar 10 conversas nos 7 perfis |
| 14 | Cap. 13 | Reescrever a mesma oferta para os 4 estilos DISC |
| 15 | Revisão | Roleplays 5 e 10 |
| | **Semana 4: preço, objeções, script e playbook** | |
| 16 | Cap. 16 e 17 | Política de preço + matriz das 5 objeções mais comuns |
| 17 | Cap. 18 e 19 | Terminar toda conversa com próximo passo e data |
| 18 | Cap. 20 | Cadência de follow-up e mensagem de despedida |
| 19 | Cap. 14 e 15 | Script v1.0 por etapa do Método X1 |
| 20 | Cap. 21 e 22 | Playbook v1.0 (Anexo C) |
| 21 | Revisão | Roleplays 6, 7, 8, 9 e 11 |
| | **Dias 22 a 30: consolidação** | |
| 22 a 26 | Operação | Script v1.0 + checklist rápido em toda conversa |
| 27 | Cap. 15 | Primeiro teste A/B |
| 28 | Anexo B | 1:1 com scorecard de 3 conversas reais |
| 29 e 30 | Fechamento | Comparar com a linha de base; publicar o script v1.1 |

# Anexo C: Modelo de playbook

Preencha com a realidade da sua empresa. **Comece simples:** uma primeira versão em uma tarde já é melhor que nenhuma.

| Bloco | O que definir | Nossa versão |
|---|---|---|
| Proposta de valor | Ajudamos [quem] a [resultado] por meio de [como] | |
| Cliente ideal | Quem é, problema, por que nos escolhe, por que desiste, ticket, ciclo | |
| Personas | 2 a 4, com dor, objeção típica e perfil | |
| Campanhas | Oferta, mensagem pré-preenchida e abordagem de cada anúncio | |
| Funil e etiquetas | Critério de entrada e responsável por etapa | |
| Script | Objetivo, perguntas e critério de saída das 8 etapas | |
| Política de preço | Faixas de ticket x canal e a nossa resposta R.D.P. | |
| Objeções | As 5 mais comuns: pergunta, resposta, evidência | |
| SLA e follow-up | Prazos e cadência, com a mensagem de despedida | |
| WhatsApp Business | Perfil, catálogo, saudação, ausência, atalhos, etiquetas | |
| Conduta | Opt-out, LGPD, horário, descontos, depoimentos | |
| Métricas | Linha de base, meta e frequência de revisão | |
| Rituais | Dia, horário, duração e responsável | |
| Versões | v1.0, data, o que mudou e por quê | |

# Glossário

**A.P.R.:** Acolher, Perguntar, Responder; método para objeções. **AIDA:** Atenção, Interesse, Desejo, Ação. **B2B / B2C:** venda para empresas / para o consumidor final. **BANT:** Orçamento, Autoridade, Necessidade, Prazo. **Cadência:** sequência planejada de follow-ups. **Call de vendas:** reunião curta, com roteiro, para apresentar solução e preço. **Closer:** vendedor do fechamento. **C.O.M.:** Conquista, Oportunidade, Mudança; estrutura de feedback. **Criativo:** a peça do anúncio. **DISC:** Dominante, Influente, Estável, Conforme. **Etiquetas:** classificação de conversas no WhatsApp Business. **Follow-up:** acompanhamento de quem ainda não decidiu. **GPCT:** Metas, Planos, Desafios, Prazo. **ICP:** perfil de cliente ideal. **Lead:** potencial cliente interessado. **LGPD:** Lei Geral de Proteção de Dados (Lei nº 13.709/2018). **Nomear a dor:** resumir o problema com as palavras do cliente. **Opt-out:** pedido para não receber mais mensagens. **Playbook:** manual operacional de vendas. **R.D.P.:** Reconhecer, Depende de quê, Pergunta; a resposta ao "quanto custa?". **Rapport:** sintonia e confiança. **Regra do Espelho:** responder no formato e no tom do cliente, com mais clareza. **Roleplay:** simulação de venda para treino. **Scorecard:** ficha de avaliação de conversa. **SLA:** prazo combinado de resposta. **SPIN:** Situação, Problema, Implicação, Necessidade de solução. **Tráfego pago:** anúncios que levam clientes até a empresa.
